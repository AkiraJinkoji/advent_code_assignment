# Cadidature pour Wandercraft - Advent of Code Challenge

Ce dépôt contient mes solutions aux quatre premiers problèmes de l’Advent of Code 2025.

## Structure
- `challenge1/code1.py`
- `challenge2/code2.py`
- `challenge3/code3.py`
- `challenge4/code4.py`

Pour exécuter un challenge, placer le fichier d’entrée `.txt` dans le dossier correspondant et adapter le chemin `file_path` dans le bloc `if __name__ == "__main__":`.
